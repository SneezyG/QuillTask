# 📝 QuillTask: Tasks & Notes in Harmony  

A **Laravel API** where your tasks and notes live together seamlessly — organize, annotate, and conquered everyday day. 

## [See QuillTask Code Repo](https://github.com/SneezyG/QuillTask)  

---

## 🚀 Key Features  

- **Organized Workflow**: Keep your tasks and notes in sync, all in one place.  
- **Task Management**: Create, update, and delete tasks with ease.  
- **Notes Integration**: Attach notes to tasks or keep them standalone.  
- **REST API**: Built with Laravel, designed for clean integration with any frontend.

---

## 📍 Use Cases  

- **Personal Productivity**: Stay on top of to-do lists while jotting down notes.  
- **Team Collaboration**: Share tasks and notes with teammates through an API-first approach.  
- **Knowledge Management**: Use notes as annotations or context for important tasks.  
- **Cross-Platform Apps**: Build mobile or web apps on top of the API.
